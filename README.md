Server-Side Word Learning App

A fast, lightweight Python & Django web application for vocabulary management and auto-generated quizzes, built with a pure server-side rendering approach and minimal JavaScript overhead.

---

Key Features
- Pure Server-Side Rendering (SSR): Optimized performance with low client-side overhead.
- Custom Vocabulary Management: Easily add and manage target words.
- Auto-Generated Quizzes: Dynamic quiz creation directly rendered from backend views.
- Minimal JavaScript: Lightweight execution for modern, resilient web access.

---

Quick Testing Instructions
To try out the quiz functionality:
1. Create an account to set up your environment.
2. Add at least 10 wordsto your personal vocabulary (required for quiz generation).
3. Start a quiz to practice your list.
